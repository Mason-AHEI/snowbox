# 技术架构文档

## 1. 架构概述

本项目采用经典的前端三层架构模式，分离展示层、样式层和逻辑层，确保代码的可维护性和可扩展性。

## 2. 文件结构

```
/
├── index.html          # 主入口页面
├── about.html          # 关于页面
├── services.html       # 服务页面
├── contact.html        # 联系页面
├── css/
│   ├── main.css        # 全局样式
│   ├── components.css  # 组件样式
│   └── responsive.css  # 响应式样式
├── js/
│   ├── main.js         # 主逻辑
│   └── components.js   # 组件交互
├── images/             # 图片资源
└── favicon.ico         # 网站图标
```

## 3. 技术选型

| 分类         | 技术    | 版本 | 说明             |
| ---------- | ----- | -- | -------------- |
| HTML       | HTML5 | 最新 | 语义化标签          |
| CSS        | CSS3  | 最新 | Flexbox/Grid布局 |
| JavaScript | ES6+  | 最新 | 现代JS特性         |
